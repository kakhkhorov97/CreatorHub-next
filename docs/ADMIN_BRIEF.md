# Dedicated administration

Mode: Operate. This is a new admin-specific interface; the public September 25 white-and-blue world remains unchanged. The user approved the management plan in /private/tmp/CreatorHub-admin-panel-plan.md and requested an independent admin page with a different style. The stated default direction is a dark sidebar and light workspace.

THESIS: An administrator can find a real record, edit it and control access or publication without using raw-ID forms.
OWN-WORLD: Fixed navy navigation, restrained blue actions, white work panels, cool light canvas, compact system-sans labels and readable tables. All figures come from backend counts.
STORY: Overview links to directories. Search and filters narrow records. Manage opens a full editing form; a separate control panel owns publication and recovery. Existing category and event forms live within the same admin shell. Website copy is saved through a backend singleton and used on public pages.
FIRST VIEWPORT: At desktop, a 232px left sidebar, 80px toolbar, a clear page heading, actual record totals and recently updated projects. Directories show filters and actual rows; editors pair content details with publication controls. At 930px content stacks. At 390px the sidebar becomes a keyboard-controlled drawer and data tables scroll within their panel.
FORM: Arial/Helvetica system sans; 28px desktop/24px mobile h1; 18px h2; 14px body; 13px form labels; 12px table data. Sidebar #111d31; canvas #f3f5f9; white panels; ink #172033; muted #576377; line #dde3ec; primary #1459df; danger #b52b31. Controls 40px minimum, 6px radius, white secondary buttons. Panel padding 24px/18px mobile. Status colors are semantic.
Signature interaction: select Manage to open the record, save edits, then explicitly confirm a publication/access/removal action. Dirty forms block status actions. Removal retains records; restoring content does not republish it.
Motion: drawer movement only, 200ms, disabled for reduced motion.

No new raster asset or generated comp is part of the admin scope. Existing portfolio thumbnails are backend-owned records. This implementation follows the approved layout directly in code. The Impeccable launcher/detector was unavailable earlier in the session, so review uses source, screenshots and actual workflow evidence; there is no detector verdict.
