# CreatorHub presentation screenshots

The package contains 22 PNG images: 11 desktop views and 11 mobile views. Desktop images are plain browser screenshots at 1440 × 1000. Mobile images show the actual 390 × 760 responsive website inside an illustrative iPhone-style frame. The PNG backgrounds outside the frame are transparent. Original mobile captures remain in mobile-raw in the project.

Nine main pages are included: Home, Projects, Creators, a creator profile, a project detail, Services, FAQ, the AI assistant and Inbox. Extra views show the popular-project section and the creator work gallery. No explanations are embedded in the images. No PDF or PowerPoint has been created.

The Inbox screenshots use an isolated fictional conversation, with portraits served from the public backend media. No live member conversations appear in the package. Fictional portfolio content and AI-generated artwork are disclosed on the website.
